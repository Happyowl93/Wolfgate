# IreWarnings

Overload warnings for the IRE (the antimatter engine). Injecting more than two units per core wears the cores
down, and the engine explodes when their mean integrity reaches zero; until now the only sign was the controller's
sprite.

The controller window shows the engine's core stability (mean core integrity, amber below 80%, red below 50%) and
its safe injection limit (two per core). `AmeControllerSystem.WGTryGetIreReadout` reads both; the window state
gets them from a marked hook in `AmeControllerSystem.UpdateUi`.

`WGIreWarningSystem` checks every injecting controller once a second. Below 50% stability it sounds a buzzer and
shows a large popup to everyone within 12 m, naming the stability and the safe limit, at most once every 15
seconds per controller.

`WGIreWarningTest` builds a one-core engine, overloads it and checks the readout and the warning's cooldown.

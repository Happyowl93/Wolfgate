# SwarmMissileLauncher

Artwork for a superheavy ship-mounted swarm missile launcher: four armored launch banks on a broad mount,
with a central targeting spine and red status indicators. This module currently supplies the sprite only;
players and admins have no new spawnable weapon until an entity prototype is added.

The entry point is `Resources/Textures/_WF/SwarmMissileLauncher/swarm_launcher.rsi`, state `space_artillery`.
It has one static 128 x 128 frame, facing south, with a centered canvas anchor and at least 10 pixels of
transparent border around the occupied artwork. Its visible bounds are `(10,16)` through `(117,115)`.
The body and indicators share the normal sprite layer; there is no emissive overlay or firing animation.

The Vespera, Vanquisher and Trident sprites were inspected as local references. Vespera already supplies a
medium-mount swarm rack; this artwork has a larger 108 x 100 occupied footprint and four launch banks.
No pixels were copied. The six steel shades and two red shades match Vespera's measured palette.

Artwork was generated using the built-in OpenAI image-generation tool, then converted in Aseprite to the
native canvas, binary alpha and material ramp. The authoring artifacts retain the generated source,
generation prompts, conversion script and editable Aseprite source with separate body, cleanup and indicator layers.
Only the runtime RSI is included here. The asset is licensed under CC-BY-SA-3.0 as recorded in `meta.json`.
